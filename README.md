# Brote · Café y matcha

Landing page de Brote, una cafetería ficticia de especialidad y matcha en Palermo, Buenos Aires.

Sitio estático: HTML, CSS y JavaScript, con [GSAP](https://gsap.com/) y ScrollTrigger (desde cdnjs) para las animaciones.

## Estructura

```
index.html        Página principal
creditos.html     Créditos y licencias de las fotos
css/styles.css    Estilos
js/main.js        Menú, pestañas de la carta y animaciones
assets/           Logo y fotos (WebP)
favicon.svg
```

## Ver en local

```bash
npx serve .
```

## Publicar en Vercel

Importá el repositorio en Vercel como proyecto estático. No hace falta comando de build y la carpeta de salida es la raíz.

## Fotos

Las fotografías son de Wikimedia Commons, bajo licencias CC0, CC BY y CC BY-SA. El detalle de cada una está en `creditos.html`.

El nombre, el logo, los precios y los horarios son ficticios.
